# toothfulapp/.github

Organization-wide defaults. GitHub applies the files under `.github/` to every repo in
`toothfulapp` that doesn't define its own.

- `.github/ISSUE_TEMPLATE/` — Bug, Feature, Task, and Tech debt issue forms. Each sets the issue
  type and adds the issue to the [Toothful App](https://github.com/orgs/toothfulapp/projects/1)
  board. Blank issues are disabled.

A repo that adds its own `.github/ISSUE_TEMPLATE/` stops inheriting these, so customise here.
